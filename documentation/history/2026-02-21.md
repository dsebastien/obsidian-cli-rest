# 2026-02-21

## Dynamic CLI Command Discovery

Implemented hybrid discovery + pass-through for CLI commands.

### New files

- `src/app/services/cli-command-discovery.ts` — `parseHelpOutput()` and `discoverCliCommands()` functions. Parses `obsidian help` output to discover commands. `DiscoveredCommand` type with `command`, `description`, `section` fields.
- `src/app/services/cli-command-discovery.spec.ts` — Tests with captured help output snapshot (CLI 1.12.2).

### Modified files

- `src/app/domain/cli-command-registry.ts` — Added runtime merge capability: `mergeDiscoveredCommands()`, `resetDiscoveredCommands()`, `isDangerousPattern()`. `getCommandDefinition()` and `getAllCommands()` now return merged set (static + discovered). Static entries always win.
- `src/app/plugin.ts` — Added `discoverCommands()` private method called after CLI availability check in `onload()` and `recheckCli()`. Added registration of `copy-rest-url` and `copy-mcp-url` commands.
- `src/app/services/request-router.ts` — Changed unknown command behavior from 404 to pass-through via POST. Non-POST methods for unknown commands return 405. Ephemeral definitions use safe defaults with dangerous pattern detection.
- `src/app/commands/toggle-server.ts` — Added `registerCopyRestUrlCommand()` and `registerCopyMcpUrlCommand()` functions.

### Test changes

- `src/app/domain/cli-command-registry.spec.ts` — Added `afterEach(resetDiscoveredCommands)` for test isolation. Added tests for `mergeDiscoveredCommands`, `resetDiscoveredCommands`, `isDangerousPattern`.
- `src/app/services/request-router.spec.ts` — Changed "returns 404 for unknown CLI command" test to verify 405 (GET not allowed for pass-through). Added pass-through tests: POST succeeds, DELETE returns 405, dangerous pattern detection, blocked list, CLI unavailable.

### Documentation

- Updated Architecture.md, Domain Model.md, Business Rules.md with discovery flow, `DiscoveredCommand` type, and new business rules.

### Key decisions

- POST is the only allowed method for pass-through commands (safest default).
- Static registry entries always take precedence over discovered ones.
- Discovery failure is non-fatal — graceful fallback to static-only.
- Dangerous pattern detection uses regex matching business rules (`dev:*`, `eval`, `restart`, `reload`, `devtools`, `command`, `plugins:restrict`).

## Internal Commands

Added two internal commands (`cli-rest:rest-url`, `cli-rest:mcp-url`) handled by the plugin without calling the CLI binary. These return the REST API base URL and MCP server URL respectively. They work even when CLI is unavailable. Also added command palette commands to copy these URLs to clipboard.
